# Straight Distance

골프장(어디든)에서 폰으로 여는 한 페이지. 홈 화면에 추가하면 이름은 **Straight Distance**. 위성지도 위에 내 GPS 위치가 찍히고, 지도를 **꾹 누르면** 그 자리가 핀,
내 위치에서 핀까지 **직선거리(m)** 를 크게 보여준다. 고저차가 있으면 그 아래 **보정거리(plays-like)** 한 줄. 그게 전부다.

- 주소: https://chofafa.github.io/straight-distance/ (GitHub Pages, `main` 브랜치 루트)
- 지도: VWorld(국토지리정보원) 위성 타일 `https://xdworld.vworld.kr/2d/Satellite/service/{z}/{x}/{y}.jpeg` — z19(0.24m/px)까지 원본, 그 위는 확대. 키 없이 받아진다(개인 용도)
- 지도 엔진: Leaflet 1.9.4 (cdnjs)
- 표고: AWS Terrain Tiles `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/15/{x}/{y}.png` — 키 없음, CORS 열림, 한국은 SRTM 30m
- 저장: 마지막 핀·화면 위치, 받아둔 표고 타일(최대 6장)을 그 폰의 localStorage 에
- 기본 화면: 베어크리크 춘천 클럽하우스. GPS 가 잡히면 첫 한 번 내 위치로 옮긴다 — 어느 골프장이든 된다

## 왜 claude.ai 아티팩트가 아닌가

아티팩트는 iframe 안에서 돌아 **위치 권한이 원천 차단**되고, CSP 가 외부 지도 타일을 막는다.
GPS 와 고화질 타일이 핵심이라 독립 호스팅이 필요했다 (2026-09-09).

## 고저차 보정 (plays-like)

핀 두 점의 표고를 받아 **보정거리**를 한 줄 더 보여준다. 오르막이면 늘고 내리막이면 준다.
보정해도 1m 미만이면 그 줄은 아예 안 나온다 — 평지에서 화면이 늘어나지 않게.

```
plays = d + Δh / tan(65° − 0.12 × clamp(d + Δh, 80, 220))
```

보이스캐디(APL골프) 안드로이드 앱이 쓰는 식 그대로다. 괄호 안은 볼의 낙하각이라 **거리마다 보정 계수가 다르다** —
80m 0.69 / 120m 0.82 / 150m 0.93 / 180m 1.06 / 220m 1.25. 짧은 샷은 탄도가 가팔라 덜 먹고, 길수록 얕아 더 먹는다.

표고 타일은 받는 즉시 localStorage 에 캐시한다(최대 6장 ≈ 골프장 하나). 라운드 중 신호가 끊겨도 그 코스는 계속 보정된다.
표고를 못 받으면 보정거리 줄만 조용히 사라지고 직선거리는 그대로 나온다.

## 오차

이중주파수 아이폰(14 Pro 이후) ±2~3m, 구형 ±3~5m, 숲·계곡 5~15m. 오른쪽 위 상태칩이 ±m 를 보여준다.
핀을 손으로 찍는 오차 2~3m 를 더하면 실전 ±5m 안팎.

**고저차 쪽 오차** — 베어크리크 춘천 공식 홀 공략도와 대조한 결과 티→그린 고저차는 **2~3m** 안쪽이다
(18번 −31.8 / 공략도 −34, 16번 +29.8 / +30, 17번 −0.3 / +2).
같은 좌표에서 Copernicus 90m 는 평지인 17번을 +26m 오르막으로, ASTER 30m 는 16번을 +41m 로 봤다 — 그래서 SRTM 30m 를 쓴다.
⚠️ **페어웨이 중간 지점은 아직 실측 대조를 못 했다.** 30m DEM 은 절토·성토로 깎아 만든 페어웨이를 원지형으로 보기 때문에
끝점(티·그린)보다 오차가 클 수 있다. 세컨드 샷 거리를 믿기 전에 실제 라운드에서 몇 번 대조해볼 것.

## 고치기

`index.html` 한 파일. push 하면 1분쯤 뒤 반영된다. 로컬 확인은 `python3 -m http.server` 로 열면 되지만
GPS 는 https 또는 localhost 에서만 뜬다.
